## 我们不做的事

- **不清** PowerShell / POSIX 双跑脚本（只 PS）
- **不打包** 二进制（链接 + SHA256 only）
- **不翻译** 所有 aspirations（只中文）
- **不确认可写的 Wins**：实验性（brewing window manager）Thing 不推

## 一句经验

> 与其做"东西齐的 wiki"，不如做 "AI agent 跑错时能像模看表" 这样 "AI agent 遇到一步该停" 是 80% 的 wins。 - [zzwcoding README](https://github.com/zzwcoding/weread-kpw3) 英文："The repo is aimed at Agent consumption: the doc is written so an Agent receiving the repo can reproduce it." —— 这是 vision 级 statement，我们 AGENTS.md 也是同 vision。

## 阈值声明

- 我们的 content 是中文 only，别人是多语 / agent-cons oriented。
- 我们的 version target 是 1 个设 (PW3/5.16.2.1.1)，别人是 dig 了 cellar/oasis3/docs-page 了的人。
- 我们 8 个 iron-law 你必须 read first，别人 8 = 90% 的 finding is "you can do it on your own" —— we never fight you on that.
- 我们 have desensitization-check CI, others have none.
- 包括link 致谢，我们 是 "link to, attribute to, don't copy" 的 purist。
