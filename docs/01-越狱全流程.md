# 01 · 越狱全流程（LanguageBreak + KOReader + 微信读书）

> 从零到"能在墨水屏上读微信读书"的完整可复现流程，基于 2026-10 在一台 Kindle Paperwhite 3（4GB，固件 5.16.2.1.1）上的真实操作。**四个坑写在对应步骤里**——它们是别的教程语焉不详、实际最可能让你卡住的地方。
>
> 前提：固件 ≤ 5.16.2.1.1。若不是，本流程不适用——去 kindlemodding.org 的 [Jailbreak Wizard](https://kindlemodding.org/jailbreak-wizard.html) 查可用方案。

## 方案选择

按 2026-10-15 从 kindlemodding 官方 wiki 逐页核对的结果（**具体机型/固件区间只能在 [Jailbreaking Wizard](https://kindlemodding.org/jailbreak-wizard.html) 里输入序列号+固件才能确定，wiki 各页都只写"以 wizard 为准"，不留静态表**）：

| 方案 | 发布 / 作者 | 前置条件（官方原文） | 对 PW3 / 5.16.2.1.1 是否可行 |
|---|---|---|---|
| **LanguageBreak ✓** | 2023-11 前 / Marek | 一台 Kindle + 一台电脑。**不需要注册、不需要联网** | ✅ 官方明确 "will NOT work on firmwares newer than 5.16.2.1.1"，5.16.2.1.1 正中红心 |
| WinterBreak | 2025-01-01 / Hackerdude | 已注册机型 + 联网 | ⚠️ 瓶颈是**网络可达性+商店行为**，不是注册状态（社区经验，未实测） |
| AdBreak | 2025-09-24 / hhhhhhhhh | 已注册 + **有广告**的机型 + 联网 | ⚠️ 同上，另要求有广告版本 |
| SpringBreak | 2026-06-22 / Penguins184 | 已注册机型 + 联网 | ⚠️ 同上 |
| Nosebleed | 2026-03-02 / hhhhhhhhh | 机型 + 联网（FAQ 称对部分黑名单设备有效） | ❌ 固件过低 |
| WinterBreak2 | 浏览器式 / Scam.Net + Penguins184 | 联网；故障排查里说"固件低于 5.16.4 请改用原版 WinterBreak" | ❌ 固件过低 |
| Sanctuary | 2026-06-30 / Ava、Alysa、sparklerfish | 机型 + 联网（用 Kindle 浏览器） | ❌ 固件过低 |
| Véra | 2026-08-10 / Ava、sparklerfish | 机型 + 联网 | ❌ 固件过低 |
| SpiderCat | 2026-09-01 / sparklerfish | 机型 + 联网 | ❌ 固件过低 |

官方 wiki 把 Legacy（LanguageBreak 等）标成 "no-longer recommended in favour of simpler methods such as WinterBreak"。**但 WinterBreak 的前置条件是"已注册机型"——国内设备因为电子书店 2023-06-30 停运，注册这条路基本走不通**。所以 LanguageBreak 仍是 5.16.2.1.1 设备的可行解。官方 FAQ 也留了话："For devices on firmware 5.16.2.1.1 or below, you can try any of the jailbreaking methods listed in Legacy Jailbreaks."

**"官方推荐 ≠ 你的最优解"。**

---

## 步骤 01 · 查固件与型号

- 设置 → 右上角三点 → 设备信息，第一行；或
- 插 USB 看 `<盘符>:\system\version.txt`（盘符以你的实际挂载为准）。

确认固件 ≤ 5.16.2.1.1。

## 步骤 02 · 电量 ≥ 50% 并移除密码锁

- 电量 ≥ 50%，最好插电。
- 移除设备密码锁。

## 步骤 03 · 清除根目录 .bin 残留

删除 `<盘符>:\*.bin`——残留的更新包会干扰。

## 步骤 04 · 全量备份设备

越狱流程会清空用户存储。用 `scripts/backup-device.ps1` 或手动 `robocopy` 镜像整个 Kindle 盘到备份目录。

## 步骤 05 · 下载安装包

按 `data/jailbreaks.yaml` 里的下载链接获取所有安装包。

## 步骤 06 · 校验安装包哈希与魔数

用 `scripts/verify-artifacts.ps1` 对每个包做 sha256 与魔数校验。

## 步骤 07 · 解压安装包

```powershell
tar -xzf "LanguageBreak.tar.gz"
```

解压后得到：根目录的 `update_hotfix_languagebreak.bin`、`DEVICES.txt`、`README.MD`，以及 `LanguageBreak\` 文件夹（内含 `.demo\boot.flag`、`jb`、`patchedUks.sqsh`、`DONT_CHECK_BATTERY`、`documents\dictionaries\...`）。

---

## 步骤 08 · 进入演示模式

在 Kindle 主界面**点屏幕最顶部时间区**调出搜索栏，输入：

```
;enter_demo
```

回车（PW3 触屏键盘的提交键在右下角）。**立刻长按电源键 7 秒 → 选"重启"**。

## 步骤 09 · 绕过演示模式错误画面

> ⚠️ **坑 ①**

重启后你会进演示模式，但**大概率卡在一个画面**：屏幕下方有一行字（大意是"本演示设备内容缺失或未联网"）和一个点了没反应的"配置设备"按钮，**顶部没有搜索栏，也退不出去**。这是 LanguageBreak 流程里一个**正常的中间态**，不是卡死——原因是还没拷入 `.demo\boot.flag`，演示内容当然"缺失"。

**正确的解锁手势**（对着那行错误文字/"配置设备"区域）：

1. **两根手指并拢**（食+中指），**同时**按在那行错误文字上，轻点一下
2. **紧接着**用**一根手指**从屏幕**右下角**划到**左下角**（从右往左，横扫屏幕底部）
3. 成功标志：**顶部出现搜索栏**

容易做不准的点：手指要**同时**落下；滑动方向一定是**从右往左**。多试几次。这个手势来自 LanguageBreak 的 GitHub issue #76 和官方 wiki。

## 步骤 10 · 侧载内容 + 第一次拷入

搜索栏输入 `;demo` 回车 → 进演示配置菜单 → 选 **Sideload Content（侧载内容）** → 插 USB。

电脑上把 `LanguageBreak\` 文件夹**里的全部内容**拷到 `F:\` 根目录（覆盖）。关键文件包括隐藏的 `.demo\boot.flag`（PowerShell 用 `robocopy /E`，会带隐藏文件）：

```powershell
robocopy "LanguageBreak" "F:\" /E /IS /IT /R:1 /W:1
```

验证：`F:\.demo\boot.flag`、`F:\jb`、`F:\patchedUks.sqsh`、`F:\DONT_CHECK_BATTERY` 都在。

## 步骤 11 · 转售设备 + 第二次拷入（抢时间）

安全弹出 → **拔掉 USB** → 回演示配置菜单（再做一次解锁手势 + `;demo`）→ 选 **Resell Device（转售设备）** → 确认 Yes。

**当 "Press the Power Button / 请按电源按钮" 画面一出现，立刻把 USB 插回去**，马上做第二次拷贝：

```powershell
robocopy "LanguageBreak" "F:\" /E /IS /IT /R:1 /W:1
```

（同样覆盖。）拷完安全弹出。**这时才**长按电源键，直到设备重启。

## 步骤 12 · 选简体中文触发漏洞

重启后出现**语言选择界面**（不是正常界面）。找 **简体中文**（在列表靠下，在一个叫 "Pseudot" 的怪条目上方、日语下方），点它，确认。

设备再次重启，**重启过程中屏幕右上角出现白色日志文字** = 越狱触发成功。

## 步骤 13 · 应用 hotfix

重启后设备可能停在"连接网络/注册演示样机"界面。**不要连网**，按：

1. 搜索栏输入 `;uzb` 回车（启用演示模式下的 USB 访问）
2. 插 USB，把 `update_hotfix_languagebreak.bin` 拷到 `F:\` 根目录
3. 安全弹出
4. 搜索栏输入 `;dsts` 回车 → 进设置页 → 找 **"更新您的 Kindle"** → 点确认 → 进度条跑完自动重启
5. 重启后**回到正常主界面** = hotfix 成功，越狱已永久化

## 步骤 14 · 验证越狱

搜索栏输入 `;log`。右上角出现日志文字 = 桥接活跃，越狱确认。`F:\` 根目录会有 `mkk\`、`LanguageBreakRan`、`languagebreak_log`。

---

## 步骤 15 · 安装 MRPI + KUAL

> ⚠️ **坑 ②：PEKI 在这台机器上静默失败**

kindlemodding 官方 wiki 对 K5+ 推荐 **PEKI**：把 `KUAL.jar` + `KUAL.sh` 放进 `documents\`，书库里就会出现 KUAL 条目。**但在 PW3 / 5.16.2.1.1 上实测失败**——拷入并重启后书库里始终不出现。推测是该固件已不再索引 `documents\` 下的 `.jar`。

退回**经典 MRPI + KUAL Booklet coplate** 路线，它走越狱桥接，不依赖 Kindle 的 jar 签名校验：

1. 解压 `kual-mrinstaller.tar.xz`，把里面的 `extensions\` 和 `mrpackages\` 拷到 `F:\` 根目录（覆盖）
2. 解压 `KUAL-coplate.tar.xz`，把 `Update_KUALBooklet_c6ac782_install.bin` 拷进 `F:\mrpackages\`
3. 安全弹出
4. 搜索栏输入 `;log mrpi` 回车（注意是 **m-r-p-i**）
5. 屏幕底部出现 **"Hush, little baby..."**，然后自动安装、自动重启 UI
6. 重启后书库里出现 **KUAL** 条目 = 成功

**注意：不需要单独装 `developer.keystore`**。MRPI 走越狱桥接，绕开了 jar 签名校验。

## 步骤 16 · 安装 KOReader

1. 解压 `koreader-kindle-legacy-v2026.07.1.zip`，得到 `koreader\`、`extensions\`、`launchpad\` 三个文件夹，全拷到 `F:\` 根目录（覆盖）
2. 安全弹出
3. 书库 → 打开 KUAL → 菜单里找 KOReader → Start KOReader

> ⚠️ **坑 ③：KOReader 运行时 USB 不挂载**

KUAL 以"无框架（frameworkless）"方式启动 KOReader——为了省内存把 Kindle 原生 UI 杀了，连带 USB 存储服务也停了。所以 KOReader 还开着的时候，**插 USB 电脑认不到盘**。

要传文件：在 KOReader 里点顶部 → ≡（左上角）→ 拉到最底 → 退出 → 退出 KOReader，回原生主界面后再插 USB。备选：KOReader 工具菜单里也有"启动 USB 存储"，但直接退出更干净。

## 步骤 17 · 安装微信读书插件

1. 解压 `weread.koplugin-v1.6.0.zip`，把 `weread.koplugin\` 拷进 `F:\koreader\plugins\`
2. 安全弹出
3. KOReader 起来后，顶部菜单 → 工具 → 应能看到 **微信读书**

---

## 步骤 18 · 阻断 OTA（连 WiFi 之前必须做）

不阻断的话，一旦连 WiFi，亚马逊会自动推 5.16.3+ 固件，越狱环境当场报废。

1. 解压 `BinaryRenamer.zip`，把 `BinaryRenamer\` 拷进 `F:\extensions\`
2. 弹出 → 书库 → 打开 KUAL → 菜单里找 **BinaryRenamer** → **Block OTA Updates** → 确认
3. 它会重命名系统里的 `otaupd`→`otaupd~`、`otav3`→`otav3~`
4. 选 Reboot 重启使生效

副作用（预期内）：系统设置里的"更新您的 Kindle"将不再起作用。要解除就去 BinaryRenamer 里选 Restore OTA Updates。

## 步骤 19 · 登录微信读书

1. 手机打开 **微信读书 App** → 我 → 设置 → **微信读书 Skill** → 获取 API Key
2. Kindle 上 KOReader → 工具 → 微信读书 → **微信扫码登录**
3. 微信扫码，手机确认，手机上会显示 4 位验证码，在 KOReader 里输入

之后就能：书架同步、整本下载 EPUB 离线看、阅读进度同步、阅读时长上报、划线/想法查看、公众号文章。详见插件自带菜单。

## 卡住了怎么办

这三条来自 kindlemodding 官方 LanguageBreak 页面，会话里当时没用上，但都是能救命的：

**① 换个姿势进演示模式**（`;enter_demo` 没反应时）：

1. 插 USB，在 `F:\` 根目录建一个**空文件**，名字就叫 `DONT_CHECK_BATTERY`
2. 搜索栏输入 `;demo` 回车
3. 然后从"进入演示模式"那步继续

**② 卡在演示模式里想恢复出厂**：

1. 搜索栏输入 `;uzb` 回车
2. 插 USB，在 `F:\` 根目录建一个**空文件**，名字叫 `DO_FACTORY_RESTORE`
3. 重启 Kindle

> 注意：官方流程的第 1 步其实是**先恢复出厂设置**再 `;enter_demo`。本流程是从已有数据的状态直接进的演示模式，也成功了（阶段 0 已备份），但官方推荐恢复出厂后开始，能少很多奇奇怪怪的状态。

**③ 秘密手势做不准**：官方页面附了演示视频（"Secret Gesture Video"），搜 "LanguageBreak secret gesture" 或直接看 wiki 该页。

## 一句话红线

固件**永远停在 5.16.2.1.1**，平时飞行模式，下载/同步时才开 WiFi，要传文件先退出 KOReader。其余见 `02-日常使用与维护.md`。
