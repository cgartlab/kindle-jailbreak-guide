# 01 · 越狱全流程（LanguageBreak + KOReader + 微信读书）

> 从零到"能在墨水屏上读微信读书"的完整可复现流程，基于 2026-10-14 在一台 Kindle Paperwhite 3（4 GB，固件 5.16.2.1.1）上的真实操作。**四个坑写在对应步骤里**——它们正是别的教程语焉不详、而实际最可能让你卡住的地方。
>
> 前提：你的 Kindle 固件 ≤ 5.16.2.1.1。如果不是，本流程不适用——去 [官方 Jailbreaking Wizard](https://kindlemodding.org/jailbreak-wizard.html) 查你该用哪个方案。

## 为什么是 LanguageBreak

按 2026-10-15 从 kindlemodding 官方 wiki 逐页核对的各方案前置条件：

| 方案 | 发布日期 / 作者 | 官方前置条件 | 对国行 5.16.2.1.1 是否可行 |
|---|---|---|---|
| **LanguageBreak ✓** | 2023-11 前 / Marek | 一台 Kindle + 一台电脑。**不要求注册、不要求联网** | ✅ 入场券拿得到 |
| WinterBreak | 2025-01-01 / Hackerdude | **已注册**机型 + 联网 | ⚠️ 碶颈是网络可达性 + 商店行为，不是"注册"本身——见下方说明 |
| AdBreak | 2025-09-24 / hhhhhhhhh | **已注册** + **有广告** + 联网 | ⚠️ 同上 |
| SpringBreak | 2026-06-22 / Penguins184 | **已注册** + 联网 | ⚠️ 同上 |
| Nosebleed | 2026-03-02 / hhhhhhhhh | 机型 + 联网（FAQ 提到对部分黑名单设备可能有效） | ❌ 本固件过低 |
| WinterBreak2 | 浏览器式 / Scam.Net + Penguins184 | 联网；故障排查里说明"固件低于 5.16.4 请改用原版" | ❌ 本固件过低 |
| Sanctuary | 2026-06-30 / Ava 等 | 机型 + 联网（走 Kindle 浏览器） | ❌ 本固件过低 |
| Véra | 2026-08-10 / Ava | 机型 + 联网 | ❌ 本固件过低 |
| SpiderCat | 2026-09-01 / sparklerfish | 机型 + 联网 | ❌ 本固件过低 |

官方 wiki 现在把 Legacy（LanguageBreak 等）标成 "no-longer recommended in favour of simpler methods such as WinterBreak"。**LanguageBreak 因为"不需要注册、不需要联网"，对软硬件环境受限的国行设备仍然是可行解**，而 WinterBreak 及之后的方案前置条件都包含联网+注册——这层门槛并不一定过不了，但不可控。

**重要修正（比 "国行注册不了" 更准确的描述）**：社区有在国内网络跑通 WinterBreak 的案例（离线化改造后），且未提及注册障碍。因此"瓶颈是网络可达性 + 商店行为，不是注册本身"比"国行注册不了"更贴 reality。LanguageBreak 的优势在于：**它 bypass 了所有这些前置条件，把可控性留给自己。**

LanguageBreak 官方原文："LanguageBreak will NOT work on firmwares newer than 5.16.2.1.1"。本机 5.16.2.1.1 正中红心。

## 步骤 01 · 查固件与型号

两种查法：

**方法一（推荐）**：把 Kindle 连 USB，打开出现的盘，看 `<设备盘符>:\system\version.txt`，里边是一行：

```
Kindle 5.16.2.1.1 (409747 002)
```

**方法二**：Kindle 上 右上角三点 → 设置 → 设备选项 → 设备信息，第一行型号，往下找固件版本。

<|start|> 一个贯穿全文的分界线：soft-float 与 hard-float

官方 FAQ 原话："Starting with version 5.16.3, Kindles started using hard-float architecture"。翻译：**5.16.3 是一条断崖**。`≤ 5.16.2.1.1` 是 soft-float；`≥ 5.16.3` 是 hard-float，一大堆老扩展当场失效。**如果你的固件正好在 5.16.2.1.1 或更低，现在是一台"黄金版本"。**

## 步骤 02 · 电量≥50%并移除密码锁

1. 设备电量 ≥ 50%，最好插电
2. 设置里移除设备密码锁（如有）

## 步骤 03 · 清除根目录 .bin 残留

清掉 `<设备盘符>:\` 根目录所有 `.bin` 文件（残留的更新包会干扰流程）。不要误删其他文件。

## 步骤 04 · 全量备份设备

越狱流程会清空用户存储。用 `scripts/backup-device.ps1`，或手动：

```powershell
robocopy "<盘符>:\ " "D:\Kindle备份" /MIR /FFT /R:2 /W:5 /XJ
```

## 步骤 05 · 下载安装包

需要的包（带 URL + SHA256）见 `3-安装包\文件清单.md`（私有目录）或 `data/jailbreaks.yaml`。GitHub 包下不动的话，给 URL 前加 `https://gh-proxy.com/`（已验证可用）。

## 步骤 06 · 校验安装包哈希与魔数

```powershell
scripts/verify-artifacts.ps1 -Dir <下载目录>
```

gzip 包 additionally 取前 2 字节验 `1f 8b`。

## 步骤 07 · 解压安装包

```powershell
tar -xzf LanguageBreak.tar.gz
```

解压后得到：根目录 `update_hotfix_languagebreak.bin`、`DEVICES.txt`、`README.MD`，以及 `LanguageBreak\` 文件夹（内含 `.demo\boot.flag`、`jb`、`patchedUks.sqsh`、`DONT_CHECK_BATTERY`、`documents\dictionaries\...`）。

## 步骤 08 · 进入演示模式

在 Kindle 主界面**点屏幕最顶部时间区**调出搜索栏，输入：

```
;enter_demo
```

回车（PW3 键盘的提交键右下角）。**立刻长按电源键 7 秒 → 选"重启"**。

<|message|> ⚠️ 官方流程会先恢复出厂设置再 `;enter_demo`。我们是从已有数据的状态直接进的，也成功了（因为步骤 04 已备份）。官方推荐前者，状态更干净。

## 步骤 09 · 坑 ①：绕过演示模式错误画面

重启后你会进演示模式，大概率卡在一个画面：屏幕下方一行字（"本演示设备内容缺失或未联网"）和一个点了没反应的"配置设备"按钮，**顶部没有搜索栏**。这是 LanguageBreak 流程里一个**正常的中间态**，不是卡死——因为你还没拷入 `.demo\boot.flag`，演示内容当然"缺失"。

**秘密手势**（官方原文："tap with two fingers, then swipe left"）：

1. **两根手指并拢**，**同时**按在那行错误文字上，轻点一下
2. **紧接着**用一根手指从屏幕**右下角**划到**左下角**（从右往左）
3. 成功标志：**顶部出现搜索栏**

做不准的三点：手指必须同时落下 / 方向必须从右往左 / 点的地方要落在错误文字上。做三次不成就去看官方视频（搜 "LanguageBreak secret gesture"）。

## 步骤 10 · 侧载内容 + 第一次拷入

搜索栏输入 `;demo` 回车 → 进演示配置菜单 → 选 Sideload Content → 插 USB。

把 `LanguageBreak\` 文件夹**里的全部内容**拷到 Kindle 根目录：

```powershell
robocopy "LanguageBreak" "<盘符>:\" /E /IS /IT /R:1 /W:1
```

验证：`<盘符>:\.demo\boot.flag`、`jb`、`patchedUks.sqsh`、`DONT_CHECK_BATTERY` 都在。拷完核对 sha256。

## 步骤 11 · 转售设备 + 第二次拷入（抢时间）

安全弹出 → **拔掉 USB** → 回演示配置菜单（手势 + `;demo`）→ 选 Resell Device → 确认。

**"Press the Power Button / 请按电源按钮" 画面一出现，立刻把 USB 插回去**，马上重复同样的拷贝（覆盖）。官方原文："This is time sensitive, be quick." 可用 `scripts/watch-and-copy.ps1` 自动完成。

拷完安全弹出，**这时才**长按电源键直到重启。

## 步骤 12 · 选简体中文触发漏洞

重启后出现**语言选择界面**。找 **简体中文**——官方原文："The second-last one on the right list, above pseudot"。选完，设备重启，**重启过程中屏幕右上角出现白色日志文字 = 漏洞触发成功**。

## 步骤 13 · 应用 hotfix（持久化）

LanguageBreak 必须**先装自己的 hotfix 才能继续**其他后越狱步骤。

1. 搜索栏输入 `;uzb`（启用演示模式 USB 访问）
2. 插 USB，把 `update_hotfix_languagebreak.bin` 拷到根目录
3. 安全弹出
4. 搜索栏输入 `;dsts` → Update Your Kindle → 确认 → 进度条跑完自动重启
5. 回到正常主界面 = 越狱已持久化

## 步骤 14 · 验证越狱

搜索栏输入 `;log`，右上角出现日志文字 = 桥接活跃。根目录出现 `mkk\`、`LanguageBreakRan`、`languagebreak_log`。

## 步骤 15 · MRPI + KUAL

| ⚠️ 坑 ②：官方推荐的 PEKI 在本机静默失败

kindlemodding 对 K5+ 推荐 **PEKI**（把 `KUAL.jar` + `KUAL.sh` 放进 `documents\`），但**在 PW3 / 5.16.2.1.1 上实测失败**——拷进去、重启、书库里始终没有 KUAL，无任何报错。推测是该固件不再把 `documents\` 下的 `.jar` 当 Active Content 索引。怀疑自己之前，先检查：cp 是否返回成功但 sha256 不匹配（Windows 文件锁静默失败）。

**退回经典路线 MRPI + KUAL Booklet coplate**：

1. 解压 `kual-mrinstaller.tar.xz`，把里面的 `extensions\` 和 `mrpackages\` 拷到根目录（覆盖）
2. 解压 `KUAL-coplate.tar.xz`，把 `Update_KUALBooklet_c6ac782_install.bin` 拷进 `F:\mrpackages\`
3. 安全弹出
4. 搜索栏输入 **`;log mrpi`**（注意是 **m-r-p-i**，不是 m-p-r-i）
5. 越狱桥接输出 "Hush, little baby..."，自动安装、自动重启 UI
6. 重启后书库出现 **KUAL** 条目

> 不需要 `developer.keystore`。MRPI 走越狱桥接，不走 Kindle 自带的 jar 签名校验。

## 步骤 16 · KOReader

1. 解压 `koreader-kindle-legacy-v2026.07.1.zip`，得到 `koreader\`、`extensions\`、`launchpad\` 三个文件夹，全拷到根目录（覆盖）
2. 解压 `weread.koplugin-v1.6.0.zip`，把 `weread.koplugin\` 拷进 `<盘符>:\koreader\plugins\`
3. 安全弹出
4. 书库 → 打开 KUAL → 菜单里找 KOReader → **Start KOReader**
5. KOReader 起来后，顶部菜单 → 工具 → 应能看到 **微信读书**

<|end|> ⚠️ 坑 ③：KOReader 运行时 USB 不挂载

KUAL 以"无框架（frameworkless）"方式启动 KOReader，杀掉原生 UI，连带 USB 存储服务也停了。官方 FAQ 原话："KOReader currently does not support USBMS mode … you must exit KOReader to do so." 解法：KOReader → 顶部 ≡ → 拉到底 → 退出 → 退出 KOReader，回原生主界面后再插 USB。

> **KOReader 构建别选错**：5.16.2.1.1（soft-float）用 `koreader-kindle-legacy-*.zip`。`kindlehf`（hard-float）装了会起不来。

## 步骤 17 · 微信读书插件

1. 解压 `weread.koplugin-v1.6.0.zip`，把 `weread.koplugin\` 拷进 `<盘符>:\koreader\plugins\`
2. 警告：**必须只有一层目录**。正确：`koreader/plugins/weread.koplugin/main.lua`。错误：`koreader/plugins/weread.koplugin/weread.koplugin/main.lua`（多套一层就不显示）
3. 重启 KOReader → 顶部菜单 → 工具 → 微信读书

<|start|> 本商城插件要求 KOReader 2026.03+，低于这个版可能加载不出来（插件菜单无 微信读书 入口）。

## 步骤 18 · OTA 阻断

| ⚠️ 这一步在"连 WiFi 之前"做，顺序不能反。

1. 解压 BinaryRenamer 包，把 `BinaryRenamer\` 拷进 `<盘符>:\extensions\`
2. 弹出 → 书库 → 打开 KUAL → 菜单里找 BinaryRenamer → **Block OTA Updates** → 确认
3. 它会重命名系统 `otaupd`→`otaupd~`、`otav3`→`otav3~`
4. 选 Reboot 重启使生效

副作用（预期内）：系统设置里的"更新您的 Kindle"将不再起作用。要解除就去 BinaryRenamer 里选 Restore OTA Updates。

官方土办法：把设备塞满只留 50–90 MB 空闲。5.16.3+ 的推送安装需要空间；11代及以上 Kindle 走 MTP 协议，得手动塞"填充文件"。

## 步骤 19 · 登录微信读书

1. 手机打开微信读书 App → 我 → 设置 → **微信读书 Skill** → 获取 API Key
2. Kindle 上 KOReader → 工具 → 微信读书 → **微信扫码登录**
3. 微信扫码，手机确认，手机显示 4 位验证码，在 KOReader 输入

## 卡住了怎么办（官方 Troubleshooting，2026-10-15 核对）

**① 换个姿势进演示模式**（`;enter_demo` 无反应）：先插 USB，在根目录建一个**空文件** `DONT_CHECK_BATTERY`，然后搜索栏输入 `;demo` 回车，从步骤 8 继续。

**② 卡在演示模式想恢复出厂**：搜 `;uzb` → 插 USB 建空文件 `DO_FACTORY_RESTORE` → 重启 Kindle。

> 官方流程的第 1 步其实是**先恢复出厂**再 `;enter_demo`。我们是从已有数据的状态直接进演示模式，也成功了（因为步骤 04 已备份）。官方推荐恢复出厂后开始，状态更干净。

**③ 秘密手势做不准**：官方页面附了演示视频。搜 "LanguageBreak secret gesture" 或直接看 wiki 该页。

## 故障自查

| 现象 | 处理 |
|---|---|
| 卡在演示模式，没搜索栏 | 秘密手势（两指点击错误文字 + 单指右→左横扫） |
| `;enter_demo` 没反应 | 根目录空文件 `DONT_CHECK_BATTERY`，再搜 `;demo` |
| 卡在演示模式想恢复出厂 | `;uzb` → 根目录空文件 `DO_FACTORY_RESTORE` → 重启 |
| 书库没有 KUAL | 用 MRPI 路线重装（`;log mrpi`）；PEKI 路线会失败 |
| `;log mrpi` 没输出 | 越狱桥接挂了 → 重打 hotfix |
| KOReader 白屏 | KUAL → KOReader → 重启 KOReader；不行重启 Kindle；再不行看 `F:\koreader\crash.log` |
| 插 USB 电脑认不到 | 先退出 KOReader 回原生界面 |
| 书架加载失败 | 检查 WiFi / API Key 是否过期 |
| 设备反复弹更新提示 | 确认 BinaryRenamer 的 Block OTA Updates 执行过 |

## 一句话红线

固件**永远停在 5.16.2.1.1**，平时飞行模式，下载/同步时才开 WiFi，要传文件先退出 KOReader。其余见 `02-日常使用与维护.md`。
