# 03 · 更新与重装

> 什么时候该动、怎么动、动坏了怎么救。

## 更新优先级

| 优先级 | 组件 | 怎么更 |
|---|---|---|
| 高 | weread.koplugin（微信读书插件） | 插件菜单 → 工具 → 微信读书 → 检查更新（需联网）。更新极勤，每隔一两个月看一眼 |
| 中 | KOReader | 除非遇到 bug，不用动。新版还是 legacy 构建，去 GitHub Releases 下 `koreader-kindle-legacy-*.zip`，解压覆盖 |
| 低 / 别动 | LanguageBreak / hotfix / mkk / MRPI / KUAL | 除非越狱挂了，不要碰 |
| 别动 | BinaryRenamer | OTA 阻断靠它，别动 |

## 更新 KOReader（覆盖法）

1. 退出 KOReader 回原生界面，插 USB
2. 备份现有设置：把 `<盘符>:\koreader\settings.reader.lua` 与 `<盘符>:\koreader\settings\` 复制到电脑留底
3. 删掉 `<盘符>:\koreader\`（或重命名成 `koreader.old` 以便回滚）
4. 解压新版 `koreader-kindle-legacy-*.zip`，把 `koreader\`、`extensions\`、`launchpad\` 拷到 `<盘符>:\`
5. 把留底的 `settings.reader.lua` 放回（设置兼容的话；不兼容就让 KOReader 重建）
6. 插件要重装：把 `weread.koplugin\` 拷回 `<盘符>:\koreader\plugins\`
7. 弹出，KUAL → KOReader 启动验证

## 重装微信读书插件

直接覆盖：

1. 退出 KOReader，插 USB
2. 解压新版 `weread.koplugin-*.zip`
3. 把 `weread.koplugin\` 拷进 `<盘符>:\koreader\plugins\`（覆盖）
4. 弹出，重启 KOReader

登录态一般会保留（存在 `<盘符>:\koreader\settings\weread.lua`）。如果丢了，重新扫码。

## 越狱挂了怎么从头来

判定越狱是否还活着：搜索栏输入 `;log`，有输出 = 活着。

- **固件还是 5.16.2.1.1**：从 `01-越狱全流程.md` 阶段步骤 13 开始重做 hotfix。多数情况重做 hotfix 就能救回。
- **hotfix 也救不回**：完整重走 `01-越狱全流程.md` 全流程。用户数据会被清空，从备份恢复书。
- **固件被升到了 5.16.3+**：LanguageBreak 不再适用，KOReader legacy 版也会失效。这是最糟情况——**只能等新的越狱手段，或换一台低固件机器**。守好 OTA 阻断红线。

## 恢复出厂 / 解除越狱

1. 先在 KUAL → BinaryRenamer → **Restore OTA Updates**（解除阻断）
2. 再做恢复出厂设置
3. 之后若想恢复越狱，重走全流程

⚠️ 恢复出厂会清掉 `documents\` 下所有东西，包括 KUAL 条目。先备份。

## 备份策略

- **越狱前镜像**：约 349MB（含 `system/`、`documents/`、`fonts/`），这是越狱前的原始状态
- **越狱后增量**：每次大改后跑 `scripts/backup-device.ps1`，生成带日期的快照
- **只备关键设置**：`<盘符>:\koreader\settings.reader.lua`、`<盘符>:\koreader\settings\weread.lua`——文件体积小，但丢了要重新调字号 / 重新登录，单独拷一份到电脑。
