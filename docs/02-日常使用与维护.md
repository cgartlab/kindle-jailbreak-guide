# 02 · 日常使用与维护

> 越狱装好之后，怎么用、怎么不弄坏。

## 环境速查

| 组件 | 版本 | 备注 |
|---|---|---|
| Kindle PW3 | 固件 5.16.2.1.1（soft-float） | **永不可升级** |
| LanguageBreak + hotfix | 1.0.1 | `mkk` 桥接活跃 |
| MRPI + KUAL | coplate c6ac782 | 书库有 KUAL 条目 |
| BinaryRenamer | v2.1 | OTA 已阻断 |
| KOReader | 2026.07.1 legacy | 从 KUAL 启动 |
| weread.koplugin | v1.6.0 | 已扫码登录 |

## 日常使用流程

**看已下载的书**（最常用，飞行模式即可，省电）：

1. 书库 → 打开 KUAL → KOReader → Start KOReader
2. 在 KOReader 文件浏览器里打开本地书

**下载新书 / 同步进度**：

1. 开 WiFi
2. KUAL → KOReader → 工具 → 微信读书 → 书架 → 选书 → 下载整本（下载成本地 EPUB）
3. 进度会自动同步、阅读时长自动上报
4. 下完关 WiFi 回飞行模式

**传书到电脑**：

1. 先退出 KOReader 回原生主界面（KOReader 运行时 USB 不挂载）
2. 插 USB，`F:` 出现（以你的实际盘符为准）
3. 书默认在 `F:\documents\` 下；KOReader 的设置/数据在 `F:\koreader\settings\`、`F:\koreader\weread\`

## 红线

- 🚫 永不升级固件。5.16.3+ 是 hard-float，KOReader legacy 版会失效，LanguageBreak 也补不上。
- 🚫 不要点"更新您的 Kindle"。BinaryRenamer 已让它失效，别去试。
- 🚫 不要恢复出厂设置。要恢复必须先在 BinaryRenamer 里 Restore OTA Updates，再操作，并做好重走越狱的准备。
- 🚫 不要随便删 `mkk\`、`libkh\`、`rp\`、`DONT_CHECK_BATTERY`、`patchedUks.sqsh`、`LanguageBreakRan`、`system\`。
- ✅ 平时飞行模式，下载/同步时才开 WiFi。
- ✅ 要传文件先退出 KOReader。

## 故障自查

| 现象 | 处理 |
|---|---|
| 书库里没有 KUAL | 重启 Kindle；仍没有就重装（`03-更新与重装.md`） |
| KUAL 打不开 / 报"未签名" | 走 MRPI 路线重装（PEKI 路线在本机不行） |
| KOReader 启动白屏 | KUAL → KOReader → 先试重启 KOReader；不行就重启 Kindle；还不行看 `F:\koreader\crash.log` |
| 插 USB 电脑认不到盘 | 先退出 KOReader 回原生界面 |
| 微信读书书架加载失败 | 检查 WiFi；检查 API Key 是否过期（微信读书 App → 我 → 设置 → 微信读书 Skill） |
| Kindle 反复弹"更新"提示 | 确认 BinaryRenamer 的 Block OTA Updates 是否真的执行过；没执行就重做 |
| `;log` 没输出 | 越狱桥接挂了，需要重装 hotfix（`;uzb` → 拷 hotfix → `;dsts` → 更新） |

## 文件位置速查

```
F:\
├── koreader\                      ← KOReader 主程序
│   ├── settings.reader.lua        ← 全局阅读设置（字号/字体/刷新）
│   ├── settings\                  ← 各插件设置（含微信读书登录态，别外传）
│   ├── weread\                    ← 微信读书书架库 + 缓存
│   └── plugins\weread.koplugin\   ← 微信读书插件本体
├── extensions\                    ← KUAL 扩展
│   ├── MRInstaller\               ← MRPI
│   ├── koreader\                  ← KOReader 启动入口
│   └── BinaryRenamer\             ← OTA 阻断
├── mrpackages\                    ← MRPI 安装包投放点（要装新扩展把 .bin 丢这里）
├── documents\                     ← 书 + KUAL.kual
└── mkk\                           ← 越狱桥接（勿动）
```

完整结构见 `04-设备文件结构.md`。

## 电量与性能

- 飞行模式 + 较低背光，续航以"周"计。
- KOReader 比 Kindle 原生阅读器吃电略多（它在跑 Lua 解释器），但差距不大。
- 觉得翻页慢：KOReader 设置里把"全刷"频率调高（比如每 20 页一次全刷），平时用局部刷新，又快又省电。
