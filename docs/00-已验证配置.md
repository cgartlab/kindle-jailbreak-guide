# 00 · 已验证配置示例

> 本文档是一份**已验证配置示例**，说明"什么样的组件版本组合在 PW3 / 5.16.2.1.1 上能跑通"。其他机型/固件请按 `data/jailbreaks.yaml` 与 [kindlemodding wizard](https://kindlemodding.org/jailbreak-wizard.html) 自行组合。

## 硬件与固件

| 项 | 值 |
|---|---|
| 型号 | Kindle Paperwhite 3（2015，第 7 代） |
| 存储 | 4 GB |
| 屏幕 | 6 寸 300 ppi |
| 触控 | 电容触屏（**无实体返回键**） |
| 固件 | `5.16.2.1.1` |
| 浮点架构 | **soft-float**（5.16.3 起改 hard-float） |
| 来源 | `<盘符>:\system\version.txt` |

## 红线

- 🚫 **永不升级固件**。5.16.3+ 是 hard-float，KOReader legacy 构建失效，LanguageBreak 也补不上。
- 🚫 **不要点系统设置里的"更新您的 Kindle"**。BinaryRenamer 已让它失效，别去试。
- 🚫 **不要恢复出厂设置**。会清掉越狱。若必须，先在 BinaryRenamer 里 Restore OTA Updates 解除阻断再操作。
- 🚫 **不要删** `mkk\`、`libkh\`、`rp\`、`system\`、`DONT_CHECK_BATTERY`、`patchedUks.sqsh`、`LanguageBreakRan`。
- ✅ 平时飞行模式阅读，下载书 / 同步进度时才开 WiFi。
- ✅ 要传文件到电脑：**先退出 KOReader 回原生界面**（KOReader 运行时 USB 不挂载）。

## 备份策略

- **越狱前镜像**：用 `scripts/backup-device.ps1` 镜像整个 Kindle 盘到备份目录。
- **越狱后增量**：每次大改后跑一次 `scripts/backup-device.ps1` 生成带日期的快照。
- **只备关键设置**：`koreader\settings.reader.lua`（字号/字体/刷新策略）与 `koreader\settings\weread.lua`（微信读书登录态）——体积小但丢了要重新调字号/重新登录，建议单独拷一份到电脑。
