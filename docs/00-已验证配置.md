# 00 · 已验证配置（reference configuration）

> 这份文件描述的是**一台已验证跑通的 Kindle Paperwhite 3（4GB，固件 5.16.2.1.1）**的完整组件版本清单——把这台机器当对照样本，方便查 "我这台跟它一样吗 / 不一样的地方在哪里"。
>
> **这是一份参考配置，不是通用模板**。其他型号与固件对应的版本号会不同。

## 硬件

| 项 | 值 | 备注 |
|---|---|---|
| 型号 | Kindle Paperwhite 3（2015，第 7 代） | KOReader `version.log` 写的 KindlePaperWhite3 |
| 存储 | 4 GB（用户可见分区 3.04 GB，空闲约 2.6 GB） | |
| 屏幕 | 6 英寸 300 ppi，电容触屏，**无实体返回键**，电源键在背部下方 | 无实体返回键这一点直接决定越狱操作手势 |
| 芯片架构 | soft-float | 5.16.3 起改 hard-float |

## 固件

| 项 | 值 |
|---|---|
| 版本 | `5.16.2.1.1 (409747 002)` |
| 来源 | `<设备盘符>\system\version.txt` |
| 架构 | soft-float（5.16.3 起 hard-float） |

**为什么这个版本是"黄金版本"**：它正好是 LanguageBreak 官方支持区间的上限（≤ 5.16.2.1.1），作者原话 "works best on 5.16.2.1"。同时它还是 soft-float 的最后一档，KOReader 有专门编译的 legacy 构建对应。**一旦升到 5.16.3，越狱手段和 KOReader 构建都会同时失效**——固件永不可升级。

## 红线（违反任意一条都可能毁掉整套环境）

- 🚫 **永不升级固件**。5.16.3+ 是 hard-float。
- 🚫 **不点系统设置里的"更新您的 Kindle"**。BinaryRenamer 已让它失效，也别去试。
- 🚫 **不恢复出厂设置**。必须先在 BinaryRenamer 里选 Restore OTA Updates 解除阻断，再操作。
- ✅ 平时飞行模式，下载/同步时才开 WiFi。
- ✅ 要传文件先退出 KOReader。
