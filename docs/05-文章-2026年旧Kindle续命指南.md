# 2026 年，旧 Kindle 续命指南

我手里有一台 2015 年的 Kindle Paperwhite 3。它在抽屉里躺了几年——因为亚马逊中国区的 Kindle 电子书店在 2023 年 6 月 30 日停运了，原生商店买不了书，那种"打开就能买"的体验没了，它就从"阅读器"退化成了"一块找不书看的墨水屏"。

但墨水屏本身没坏。300 ppi、反射式、不发光、充一次电读几周——这些优点在 2026 年依然成立，甚至比当年更稀缺（现在还在做墨水屏的厂商一只手数得过来）。

所以问题不是"这台机器还能不能读"，而是**"你打算怎么把书弄进去"**。

这篇是整套流程的记录。全部来自实机操作，不是抄教程。我会把踩过的坑写清楚，也会明确标出哪些结论是官方文档写的、哪些是只有这一台机器验证过的。

---

## 一、先认清你手里的是哪台机器

**这一步比后面所有步骤都重要**，因为越狱手段完全由固件版本决定，而固件版本决定了你**能做什么**，甚至决定了你**该不该做**。

两种查法：

**方法一（推荐，最准）**：把 Kindle 用 USB 连电脑，打开出现的那个盘，看 `system\version.txt`。里面是一行，比如我的是：

```
Kindle 5.16.2.1.1 (409747 002)
```

**方法二**：Kindle 上 右上角三点 → 设置 → 设备选项 → 设备信息，第一行就是型号，往下能找到固件版本。

记下两件事：**型号**和**固件版本**。

### 一个贯穿全文的分界线：soft-float 与 hard-float

官方 FAQ 的原话：*"Starting with version 5.16.3, Kindles started using hard-float architecture (on-chip floating point unit) for most processing tasks, compared to the soft-float architecture, which emulated in software."*

翻译成人话：**5.16.3 是一条断崖**。

- `≤ 5.16.2.1.1`：soft-float，老的越狱手段和老的 KOReader 构建都能用
- `≥ 5.16.3`：hard-float，一大堆老扩展当场失效，KOReader 要换另一套构建

官方 FAQ 说得更直白：*"most extensions found on MobileRead/Discord servers won't work on hard-float firmware or viceversa unless explicitly stated"*。

**所以：如果你的固件正好在 5.16.2.1.1 或更低，你现在手里是一台"黄金版本"，先别急着升级，看完这篇再动手。**

## 二、决定树：你的固件决定你能走哪条路

2026 年的越狱生态变化很快：新方案不断出（今年就有 Sanctuary、SpringBreak、Véra、SpiderCat、WinterBreak2 好几个），旧方案被官方划成"legacy"。**网上大部分教程的问题不是错，而是过期。**

唯一权威的判定入口是官方的 **[Jailbreaking Wizard](https://kindlemodding.org/jailbreak-wizard.html)**：输入序列号前 8 位 + 固件版本 + "能不能注册" + "有没有广告"，它告诉你该用哪个方案。

我为什么不用它、而用 LanguageBreak？因为**这台机器的最优解恰恰是官方"不再推荐"的那个**。

### 官方各方案的硬前置条件（2026-10-15 逐页核对）

| 方案 | 发布 | 官方写的前置条件 |
|---|---|---|
| **LanguageBreak** | 2023 前 | 一台 Kindle + 一台电脑。**不要求注册，不要求联网** |
| WinterBreak | 2025-01-01 | **已注册**机型 + 联网 |
| AdBreak | 2025-09-24 | **已注册 + 设备带广告** + 联网 |
| SpringBreak | 2026-06-22 | **已注册**机型 + 联网 |
| Nosebleed | 2026-03-02 | 联网（FAQ 提到对部分黑名单设备有效） |
| WinterBreak2 | — | 联网；故障排查里说"固件低于 5.16.4 请改用原版 WinterBreak" |
| Sanctuary | 2026-06-30 | 联网（走 Kindle 浏览器） |
| Véra | 2026-08-10 | 联网 |
| SpiderCat | 2026-09-01 | 联网 |

看出关键了吗：**除了 LanguageBreak，其余全部要求"已注册"或"能联网"**。

LanguageBreak 的优势在于它**不要求注册、不要求联网**。其他方案的前置条件都包含联网+注册。国行设备因为中国区电子书店 2023-06-30 停运，"注册"这条路走不通——但社区有在国内网络跑通 WinterBreak 的案例（离线化改造后），并**未提及**注册障碍。因此 "国行注册不了" 更像实践推断，不是官方结论；真实瓶颈更可能是网络可达性 + 商店行为。LanguageBreak 的优势是：**它 bypass 了所有这些前置条件，把可控性留给自己。**

官方其实也留了话。FAQ 里写着：*"For devices on firmware 5.16.2.1.1 or below, you can try any of the jailbreaking methods listed in Legacy Jailbreaks."*——**5.16.2.1.1 及以下，你可以用 Legacy 里任何一个方法。**

LanguageBreak 的官方页面更是直接写明：*"LanguageBreak will NOT work on firmwares newer than 5.16.2.1.1"*。

**结论：固件 ≤ 5.16.2.1.1 且设备注册困难（国行常见情况）→ LanguageBreak 是正解，哪怕官方把它标成 legacy。**

> 我不知道精确的"哪个机型配哪个固件能用哪个方案"的完整静态表——wiki 各页都只写"以 wizard 为准"，不公开静态表。上面的表是**前置条件**，不是**机型/固件兼容列表**。请去 wizard 确认你的机型。

## 三、三条路线，三种投入

不是所有人都需要越狱。先确认你要哪一档：

**路线 A · 零风险：只换"书的来源"**

不越狱。用 [Calibre](https://calibre-ebook.com/) 把 EPUB/MOBI 转成 Kindle 认的格式，USB 拖进 `documents\`，用原生阅读器看。零风险、零折腾，缺点是原生阅读器对 EPUB 的排版支持很一般（官方 FAQ 也承认 KOReader 才是不支持 AZW3/KFX 的那一方），也没有任何"在线书城"。

如果你只是想读自己手头的电子书文件，**到此为止，剩下的不用看**。

**路线 B · 主线：越狱 + KOReader + 微信读书**

这就是这篇要讲的。得到一个能读 EPUB/PDF/DJVU、能调排版、能装插件的阅读器，并接上微信读书——书下载成本地 EPUB，断网也能读，还能同步进度和划线。

风险：越狱流程会清空设备存储（可备份），有极小概率卡在中间状态（有恢复手段），理论上不刷底层、不变砖。

**路线 C · 已经越狱了：只做加固**

如果你已经越狱，**至少做一件事：阻断 OTA 更新**。否则设备一联网就可能被推到新固件，越狱当场报废。见下面的"红线"。

## 四、主线实操：越狱 + KOReader + 微信读书

以下步骤在 **Kindle Paperwhite 3（4GB）/ 固件 5.16.2.1.1** 上完整走通。其他机型仅供参考，**核心逻辑相同但文件版本要自己核对**。

### 阶段 0 · 准备

1. **备份**。越狱流程会清空用户存储。把整个 Kindle 盘（我的是 `F:\`）镜像到电脑：
   ```powershell
   robocopy <设备盘符>:\ "<备份目录>" /MIR /FFT /R:2 /W:5 /XJ
   ```
2. 电量 ≥ 50%，最好插电。
3. **移除设备密码锁**。
4. 清掉根目录所有 `.bin` 文件（残留的更新包会干扰）。
5. 记下你的型号和固件（第一章）。

### 阶段 1 · 越狱

**需要的东西**：LanguageBreak（[GitHub](https://github.com/notmarek/LanguageBreak/releases)）、一台电脑、一根 USB 数据线。

> 我下的是 `1.0.1` 的包。上游最新的 release 是 `1.0.2.1`（2023-11-06，资产名 `LanguageBreak-16.11.23.tar.gz`）。两个都能用，但**发文章这会儿你应该下最新的**。

**1. 进演示模式**

搜索栏输入 `;enter_demo` 回车，然后**立刻长按电源键重启**。

> ⚠️ **注意**：官方流程的第一步是**先恢复出厂设置**，再从语言选择界面开始操作。我是从已有数据的状态直接进的演示模式，也成功了（因为阶段 0 已备份）。官方推荐前者，状态更干净。

**2. 🕳 坑 ①：演示模式里没有搜索栏，也退不出去**

重启后你会进演示模式，但大概率**卡在一个画面上**：下方一行错误文字（大意"本演示设备内容缺失或未联网"）、一个点了没反应的"配置设备"按钮，**顶部没有搜索栏**，长按电源重启也出不来。

**别慌，这不是卡死。** 这是 LanguageBreak 流程里一个**正常的中间态**——因为你还没把 `.demo\boot.flag` 拷进去，演示内容当然"缺失"。

官方页面把这个绕过方式写成了一行小字：

> *"Once that is done, you can bypass the misconfiguration error using the following gesture: (tap with two fingers, then swipe left)"*

**正确的秘密手势**（对着那行错误文字/"配置设备"区域）：

1. **两根手指并拢**（食+中指），**同时**按在那行错误文字上，轻点一下
2. **紧接着**，用**一根手指**从屏幕**右下角**划到**左下角**（从右往左，横扫屏幕底部）
3. 成功标志：**顶部出现搜索栏**

做不准的三个地方：手指要**同时**落下不是先后；方向一定是**从右往左**；点的地方要落在**错误文字上**。官方页面附了演示视频，做三次不成就去看视频。

我第一次在这里卡了很久，因为一开始靠猜手势，猜错了。**这是整篇里最值得记住的一条。**

**3. 进配置菜单，第一次拷文件**

搜索栏输入 `;demo` → 进演示配置菜单 → 选 **Sideload Content（侧载内容）** → 插 USB。

把 LanguageBreak 文件夹**里的全部内容**拷到 Kindle 根目录（覆盖）。**注意包含隐藏的 `.demo` 文件夹**（PowerShell 用 `robocopy /E` 会带上隐藏文件）：
```powershell
robocopy "LanguageBreak" "F:\" /E /IS /IT /R:1 /W:1
```
验证 `F:\.demo\boot.flag`、`F:\jb`、`F:\patchedUks.sqsh` 都在。

**4. Resell Device，第二次拷文件（这一步对时机敏感）**

安全弹出 → **拔掉 USB** → 回演示配置菜单（再做一次手势 + `;demo`）→ 选 **Resell Device（转售设备）** → 确认。

**当"请按电源按钮"的画面一出现，立刻把 USB 插回去**，然后马上重复一次同样的拷贝（覆盖）。官方原文：*"This is time sensitive, be quick."*

拷完安全弹出，**这时才**长按电源键直到重启。

**5. 选中文触发漏洞**

重启后会出现**语言选择界面**。找 **简体中文**——官方原文写得很具体：*"The second-last one on the right list, above p s e u d o t"*（右侧列表倒数第二个，在一个叫 pseudot 的条目上方）。

选完，设备重启，**重启过程中屏幕右上角出现白色日志文字 = 漏洞触发成功**。

**6. 打 hotfix（越狱持久化）**

官方特别提示：*"LanguageBreak is unique in the sense that its own Hotfix must be installed before proceeding with other Post Jailbreak items"*——LanguageBreak 必须先装它自己的 hotfix，才能装别的东西。

1. 搜索栏输入 `;uzb`（启用演示模式下的 USB 访问）
2. 插 USB，把 `update_hotfix_languagebreak.bin` 拷到根目录
3. 安全弹出
4. 搜索栏输入 `;dsts` → 进设置页 → 选 **Update Your Kindle** → 确认
5. 进度条跑完自动重启，**回到正常主界面 = 越狱已持久化**

**7. 验证**：搜索栏输入 `;log`，右上角出现日志 = 桥接活着。根目录会有 `mkk\`、`LanguageBreakRan`。

### 阶段 2 · 装启动器与阅读器

**🕳 坑 ②：官方推荐的 PEKI，在我这台机器上静默失败**

官方 wiki 对 K5 及以后的机型推荐 **PEKI**：把 `KUAL.jar` + `KUAL.sh` 放进 `documents\`，书库就会出现 KUAL 条目。**但在 PW3 / 5.16.2.1.1 上我实测失败**——拷进去、重启，书库里始终没有 KUAL。推测是该固件已不再把 `documents\` 下的 `.jar` 当 Active Content 索引。

**退回经典路线：MRPI + KUAL Booklet（coplate 版）。** 它走越狱桥接，不依赖 Kindle 自带的 jar 签名校验：

1. 解压 MRPI 包，把里面的 `extensions\` 和 `mrpackages\` 拷到根目录（覆盖）
2. 解压 KUAL coplate 包，把 `Update_KUALBooklet_*_install.bin` 放进 `F:\mrpackages\`
3. 弹出，搜索栏输入 **`;log mrpi`**（注意是 **m-r-p-i**）
4. 屏幕底部出现 **"Hush, little baby..."**，然后自动安装、自动重启界面
5. 重启后书库里出现 **KUAL** = 成功

> 这一步**不需要**额外的开发者证书（`developer.keystore`）。我提前下了，最后没用上——MRPI 走桥接，绕开了签名校验。PEKI 路线才需要。

**装 KOReader + 微信读书插件**：

1. 解压 KOReader 包，得到 `koreader\`、`extensions\`、`launchpad\` 三个文件夹，全拷到根目录
2. 解压微信读书插件，把 `weread.koplugin\` 拷进 `F:\koreader\plugins\`
3. 弹出，书库 → 打开 KUAL → 菜单里找 KOReader → **Start KOReader**
4. KOReader 起来后，顶部菜单 → 工具 → 应能看到 **微信读书**

> **KOReader 构建别选错**。KOReader 的 release 里有 `koreader-kindle-legacy-*.zip`、`koreader-kindle-*.zip`、`koreader-kindlehf-*.zip`、`koreader-kindlepw2-*.zip` 好几个。**5.16.2.1.1 这种 soft-float 老固件要用 `kindle-legacy`**（我用的就是这个，跑得好）。`kindlehf` 是 hard-float（5.16.3+），装了会起不来。

**🕳 坑 ③：KOReader 开着的时候，USB 传不了文件**

KUAL 是以"无框架（frameworkless）"方式启动 KOReader 的——为了省内存把 Kindle 原生 UI 杀了，连带 USB 存储服务也停了。**所以 KOReader 还开着的时候，插 USB 电脑认不到盘。**

官方 FAQ 确认：*"KOReader currently does not support USBMS mode (USB transfer) and will only charge the device, if you want to transfer files you must exit KOReader to do so."*

**怎么退**：KOReader 里点顶部 → 左上角 ≡ → 把菜单拉到底 → 退出 → 退出 KOReader，回原生主界面后再插 USB。

### 阶段 3 · 阻断 OTA（连 WiFi 之前必须做）

**这一步在"连 WiFi 之前"做，顺序不能反。** 一旦联网，设备可能自动下载并安装新固件，越狱当场报废。

1. 把 BinaryRenamer（[原帖](https://www.mobileread.com/forums/showthread.php?t=357438)）的 `BinaryRenamer\` 拷进 `F:\extensions\`
2. 弹出 → 书库 → 打开 KUAL → 找 **BinaryRenamer** → **Block OTA Updates** → 确认
3. 它会重命名系统里的 `otaupd` → `otaupd~`、`otav3` → `otav3~`
4. 选 Reboot 重启生效

副作用（预期内）：系统设置里的"更新您的 Kindle"失效。要解除就去 BinaryRenamer 里选 Restore OTA Updates。

> 另一个官方推荐的土办法：**把 Kindle 塞满，只留 50–90 MB 空闲**。官方解释是更新需要空间，空间不够就装不上。这招在越狱前等待期特别有用。注意 11 代及以后的 Kindle 走 MTP 协议，不能再当 U 盘用，得手动塞"填充文件"。

### 阶段 4 · 登录微信读书

1. 手机**微信读书 App** → 我 → 设置 → **微信读书 Skill** → 获取 API Key
2. Kindle 上 KOReader → 工具 → 微信读书 → **微信扫码登录**
3. 微信扫码，手机确认，手机上显示 4 位验证码，在 KOReader 里输入

> 插件的 README 明确要求 **KOReader 2026.03 或更高**，低于这个版本插件可能加载不出来。目前插件版本更新很勤（我用的是 2026-10-05 的 v1.6.0）。

之后就能：书架同步、整本下载成 EPUB 离线看、阅读进度同步、阅读时长上报、看划线/想法、公众号文章。

## 五、四个坑（本节是全文核心）

按"最可能让人放弃"排序：

1. **演示模式里没有搜索栏、点"配置设备"没反应、重启也退不出去。** 这是正常的中间态，不是变砖。解法是那个**两指点击 + 单指从右往左横扫**的秘密手势，点的地方是**错误文字本身**。官方把它写在一行小字里，极易看漏。

2. **官方推荐的 PEKI 会静默失败。** 表现在"文件拷进去了、重启了、书库里就是没有 KUAL"，而且**没有任何报错**。碰到这个不要怀疑自己，直接换 MRPI + KUAL Booklet 路线（`;log mrpi`），实测可用。

3. **KOReader 运行时 USB 不挂载。** 会让人以为"USB 线坏了"或"电脑驱动坏了"。退出 KOReader 就好。

4. **"官方已废弃的方案"可能正是你的最优解。** kindlemodding 现在主推 WinterBreak，把 LanguageBreak 等标成 legacy。但 WinterBreak 要求"已注册机型"——对国行设备这是死路。**读文档时要看的是"前置条件"，不是"推荐等级"。**

## 六、红线

越狱不是刷固件，它是"在官方系统里撬开一个能跑自己代码的口子"。所以有些操作会把这个口子堵回去：

- 🚫 **永不升级固件。** 5.16.3+ 是 hard-float，越狱手段和 KOReader legacy 构建会同时失效。这是唯一一条真正致命的红线。
- 🚫 **不点"更新您的 Kindle"。** OTA 已阻断，也别去试。
- 🚫 **不恢复出厂设置。** 要重置的话，先在 BinaryRenamer 里 Restore OTA Updates。**另外注意**：官方 FAQ 提到，**注销（deregister）设备会清空 `documents\` 目录**——包括 KUAL 启动器条目，会导致部分扩展坏掉。
- ✅ **平时飞行模式**，只有下载书/同步进度时才开 WiFi。
- ✅ **要传文件先退出 KOReader。**
- ✅ **不要删** `mkk\`、`libkh\`、`rp\`、`system\`、`DONT_CHECK_BATTERY`、`patchedUks.sqsh`、`LanguageBreakRan`。

## 七、故障自查

| 现象 | 处理 |
|---|---|
| 卡在演示模式，没搜索栏 | 秘密手势（两指点击错误文字 + 单指右→左横扫） |
| `;enter_demo` 没反应 | 根目录建个空文件叫 `DONT_CHECK_BATTERY`，再输入 `;demo` |
| 卡在演示模式想恢复出厂 | `;uzb` → 根目录建空文件 `DO_FACTORY_RESTORE` → 重启 |
| 书库里没有 KUAL | 用 MRPI 路线重装（`;log mrpi`）；PEKI 路线在这类固件上会失败 |
| `;log mrpi` 没输出 | 越狱桥接挂了 → 重打 hotfix（`;uzb` → 拷 hotfix → `;dsts` → Update Your Kindle） |
| KOReader 白屏 | KUAL → KOReader → 试"重启 KOReader"；不行重启 Kindle；还不行看 `F:\koreader\crash.log` |
| 插 USB 电脑认不到 | 先退出 KOReader 回原生界面 |
| 书架加载失败 | 检查 WiFi；检查 API Key 是否过期（微信读书 App → 我 → 设置 → 微信读书 Skill） |
| 设备反复弹更新提示 | 确认 BinaryRenamer 的 Block OTA Updates 真执行过 |

## 八、进阶：把这台机器的价值榨干

越狱只是拿到钥匙，真正提升体验的是这几件事：

**排版**：KOReader 的字号、行距、页边距、字体全部可调，比原生阅读器自由得多。装一个趁手的中文字体丢进 `fonts\`。

**刷新策略**：墨水屏的"残影 vs 闪黑"是永恒矛盾。KOReader 里可以把局部刷新调到每 20 页全刷一次，日常翻页安静不闪，久了清一次残影。

**Calibre 联动**：Calibre 能把 EPUB 转成 Kindle 格式、管理元数据、通过 USB 或无线传给设备。和 KOReader 直接读 EPUB 两条路互补。

**划线导出**：KOReader 有 exporter 插件，能把标注导出到 Markdown / Joplin / Readwise 等。

**阅读统计**：KOReader 自带统计插件，记阅读时长和进度。微信读书插件还有单独的比较数据。

**字典**：`F:\system\dictionaries\` 放 mdict/stardict 格式字典，KOReader 直接查。

## 九、这套配置能用多久

诚实的回答：**取决于你能不能忍住不升级固件。**

- **硬件生命周期**：这块墨水屏没有机械部件，理论寿命远超电池。电池是可换的。
- **软件生命周期**：KOReader 和微信读书插件都还在活跃更新（我用的版本分别是 2026-08-01 和 2026-10-05）。只要 soft-float 构建还在发，这套就能一直跑。
- **最大风险**：误升级固件。OTA 已阻断，但"手动点更新""恢复出厂后重连 WiFi"都可能破功。

**这套配置的杠杆点在于：书是下载成本地的 EPUB。** 平台侧怎么变都不影响你已经下载的书。这是它比"在线书城"更抗风险的地方。
