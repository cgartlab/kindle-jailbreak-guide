# 04 · 设备文件结构（越狱后）

> 越狱并装好微信读书后，Kindle 插到电脑上看到的 U 盘长什么样。每个目录干什么、哪些别动。

## 顶层结构

```
<盘符>:\                          ← 根目录（USB 挂载点；SSH 下是 /mnt/us/）
├── mkk\                ★勿动    越狱桥接（LanguageBreak 装的）
├── libkh\              ★勿动    桥接依赖库（libkh\bin，越狱时装）
├── rp\                 ★勿动    空目录，用途未证实。可能是 Rescue Pack / MRPI 的残留占位目录。**别删别填**
├── launchpad\                    KOReader 启动配置
├── koreader\           ★主程序  KOReader 本体 + 微信读书插件
├── extensions\                   KUAL 扩展（MRPI / koreader / BinaryRenamer）
├── mrpackages\         空        MRPI 安装包投放点（KUAL 装完已清空）
├── documents\                    书 + KUAL 条目 + 一些可删的崩溃日志
├── fonts\                        自定义字体
├── amazon-cover-bug\             Kindle 封面 bug 的缓存（无关紧要）
├── system\             ★勿动    Kindle 系统（数据库、索引、字典、缩略图）
├── DONT_CHECK_BATTERY  ★勿动    LanguageBreak 标记文件
├── patchedUks.sqsh     ★勿动    LanguageBreak 补丁
├── LanguageBreakRan    ★勿动    越狱已运行的标记
├── languagebreak_log             越狱日志
├── driveinfo.calibre             Calibre 留的设备信息
└── metadata.calibre              Calibre 留的元数据
```

带 ★勿动 的，删了轻则越狱失效、重则需要重走整个流程。其余可以随便清理。

## 关于设备里那些 README.md

某些目录里有 `README.md`，**不是亚马逊或 KOReader 自带的**，是人工后加的目录说明注释：

- 内容是"这个目录干什么、怎么看"的白话说明，**不是运行代码**，放着不影响任何功能（KUAL 只读 `extensions\*\menu.json`，MRPI 只处理 `mrpackages\*.bin`，`README.md` 都被忽略）。
- 不想要可以直接删。
- ⚠️ **已知错误**：如果某个 `README.md` 里写的命令是 `;log mpri`，**正确的是 `;log mrpi`**（m-r-p-i，不是 m-p-r-i），别照着抄。
- KOReader 自己带的 `README.md`（`F:\koreader\README.md`、`F:\koreader\fonts\README.md` 等）是上游文档，与上面这些无关。

## 关键目录详解

### `mkk\` —— 越狱桥接
LanguageBreak 装的"MobileRead Kindlet Kit"。`;log`、`;log mrpi`、`;uzb`、`;dsts` 这些命令全靠它。里面有 `bridge.sh`、`developer.keystore`、`gandalf`、`patchedUks.sqsh` 等。**永远别动这个目录。**

### `koreader\` —— KOReader 本体
- `version.log`：确认版本和机型（如 `KindlePaperWhite3`）
- `koreader.sh`：启动脚本，KUAL 调它
- `settings.reader.lua`：全局阅读设置（字号、字体、刷新策略……）
- `settings\`：各插件的设置库。**其中含微信读书登录态，别外传**
- `weread\`：微信读书插件的数据（书架库 `library-*.db`、缓存、封面）
- `plugins\weread.koplugin\`：微信读书插件本体
- `crash.log`：KOReader 崩溃日志，出问题时给支持者看

### `extensions\` —— KUAL 扩展
KUAL 菜单里看到的每一项，对应这里一个子目录：
- `MRInstaller\` —— MRPI，包管理器（`;log mrpi`）
- `koreader\` —— KOReader 的启动入口
- `BinaryRenamer\` —— OTA 阻断工具
- `KUAL.cfg` —— KUAL 配置

### `mrpackages\`
空的。这是 MRPI 装包的投放点：以后要装新扩展（比如屏幕保护 hack），把 `.bin` 丢这里，再 `;log mrpi` 即可。

### `documents\`
- 你的书和 Calibre 传的文档
- `KUAL.kual` —— KUAL 启动器条目（点开就是 KUAL 菜单）
- `KPPMainAppV2_*_juno_*_crash_*.tgz/.txt/.sdr` —— **可删**。这是越狱演示模式期间 Kindle 系统应用崩溃留下的 dump，留着没用。

### `fonts\`
你自定义的中文字体。这些会在 Kindle 原生阅读器的字体选择里出现。

## 怎么传文件 / 备份

KOReader 运行期间 USB **不挂载**（KUAL 以无框架方式启动它）。要传文件：

1. 在 KOReader 里点顶部 → ≡ → 拉到底 → 退出 → 退出 KOReader
2. 回到 Kindle 原生主界面
3. 这时插 USB 才会挂载

备份整个设备用 `scripts/backup-device.ps1`。
