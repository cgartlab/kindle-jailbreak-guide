# 04 · 越狱后的设备文件结构

> 越狱并装好微信读书后，Kindle 插到电脑上看到的 U 盘（通常是 `<盘符>:\`）长什么样。每个目录干什么、哪些别动。

## 顶层结构

```
<盘符>:\
├── mkk\                ★勿动    越狱桥接（LanguageBreak 装的）
├── libkh\              ★勿动    桥接依赖库（越狱时装）
├── rp\                 ★勿动    用途未证实的空目录，别删别填
├── launchpad\                   KOReader 启动配置
├── koreader\           ★主程序  KOReader 本体 + 微信读书插件
├── extensions\                  KUAL 扩展（MRPI / koreader / BinaryRenamer）
├── mrpackages\         空       MRPI 安装包投放点（KUAL 装完已清空）
├── documents\                   书 + KUAL 条目 + 偶尔的崩溃日志
├── fonts\                       自定义字体
├── amazon-cover-bug\             Kindle 封面 bug 的缓存（无足轻重）
├── system\             ★勿动    Kindle 系统（数据库 / 索引 / 字典 / 缩略图）
├── DONT_CHECK_BATTERY  ★勿动    LanguageBreak 标记文件
├── patchedUks.sqsh     ★勿动    LanguageBreak 补丁
├── LanguageBreakRan    ★勿动    越狱已运行的标记
├── languagebreak_log             越狱日志
├── driveinfo.calibre             Calibre 留的设备信息
└── metadata.calibre              Calibre 留的元数据
```

带 ★ 的删了轻则越狱失效、重则需要重走整个流程。其余可随便清理。

## 关键目录详解

### `mkk\` —— 越狱桥接
LanguageBreak 装的"MobileRead Kindlet Kit"。`;log` / `;log mrpi` / `;uzb` / `;dsts` 全靠它。里面有 `bridge.sh`、`developer.keystore`、`gandalf`、`patchedUks.sqsh`。**永远别动这个目录。**

### `koreader\` —— KOReader 本体
- `version.log`：`2026-10-14, v2026.07.1, KindlePaperWhite3`（确认版本和机型）
- `koreader.sh`：启动脚本，KUAL 调它
- `settings.reader.lua`：全局阅读设置（字号 / 字体 / 刷新）
- `settings\`：各插件设置库；`settings\weread.lua` 含微信读书登录态——**别外传**
- `weread\`：微信读书插件的数据（书架库 `library-*.db`、缓存、封面）
- `plugins\weread.koplugin\`：微信读书插件本体
- `crash.log`：KOReader 崩溃日志，出问题时参考

### `extensions\` —— KUAL 扩展
KUAL 菜单里每一项对应这里一个子目录：
- `MRInstaller\` —— MRPI，包管理器（`;log mrpi`）
- `koreader\` —— KOReader 的启动入口
- `BinaryRenamer\` —— OTA 阻断工具
- `KUAL.cfg` —— KUAL 配置

### `mrpackages\`
空。这是 MRPI 装包的投放点：以后要装新扩展（比如屏幕保护），把 `.bin` 丢这里，再 `;log mrpi` 即可。

### `documents\`
- 你的书和 Calibre 传的文档
- `KUAL.kual` —— KUAL 启动器条目（点开就是 KUAL 菜单）
- `KPPMainAppV2_*_juno_*_crash_*` —— **可删**，越狱演示模式期间 Kindle 系统应用崩溃的 dump，留着没用

### `fonts\`
你自定义的中文字体（方正仿宋 / 方正中宋 / 微软雅黑等）。这些会在 Kindle 原生阅读器的字体选择里出现。

## rp\ 用途未证实

`rp\` 是一个空目录，用途未证实——可能是 Rescue Pack / MRPI 残留占位，也可能是别的组件留下。**不确定，别删别填**。如果你能证实其含义，请提 PR。

## 关于设备里那些 README.md

设别 `F:\`、`extensions\`、`mrpackages\`、`fonts\` 这几个目录里可能有中文 `README.md`——那是并发会话"整理 Kindle 文件目录"时**手写**的说明，不是亚马逊或 KOReader 自带的。内容是"这个目录干什么"的白话说明，**不是运行代码**，放着不影响功能（KUAL 只读 `extensions\*\menu.json`，`README.md` 被忽略）。不想要直接删。

⚠️ **已知错误**：`mrpackages\README.md` 里写的安装命令曾经是 `;log mpri`——**正确的是 `;log mrpi`**，别照着抄。

KOReader 自己带的 `README.md`（`F:\koreader\README.md` 等）是上游文档，与上面这些无关。

## 传文件 / 备份

KOReader 运行期间 USB **不挂载**（KUAL 以无框架方式启动它）。要传文件：

1. 在 KOReader 里点顶部 → ≡ → 拉到底 → 退出 → 退出 KOReader
2. 回到 Kindle 原生主界面
3. 这时插 USB 才会挂载

备份整个设备用 `scripts/backup-device.ps1`。
