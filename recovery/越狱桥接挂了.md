# 越狱桥接挂了

> 对应偏离状态：**S08 — 越狱桥接不活跃**
> 对应 playbook 步骤：**14（验证越狱）**
> 触发探测：锁屏输入 `;log` 回车后**屏幕右上角没有**日志图标出现。

## 怎么确认桥接挂了

锁屏（或任何非系统界面）顶部输入 `;log` → 回车。

- **桥接活跃**：屏幕**右上角**出现一个**小日志图标**（像个小旗子）。
- **桥接不活跃**：`;log` 输入后**完全无输出**，屏幕上没有任何反馈。

同样地，`;log mrpi`（注意是 m-r-p-i）没反应也是桥接不活跃。**只要有一个 `;log ...` 命令没反应，就当桥接挂了处理。**

## 补救：重打 hotfix

hotfix 已经把越狱"固化"到系统里，但**某些操作后**（更新、系统清理、某些 OTA 拦截失败）hotfix 会掉，需要重打一次。流程如下：

1. 锁屏输入 `;uzb` → 回车。**作用**：USB 挂载（USB 存储模式进入），让你能拷文件。
2. USB 接入 Kindle，把 `update_hotfix_languagebreak.bin` **拷到 Kindle 根目录**（F:）：
   ```powershell
   Copy-Item .\LanguageBreak-1.0.1\update_hotfix_languagebreak.bin F:\
   ```
3. 安全弹出 / 拔出 USB。
4. 锁屏输入 `;dsts` → 回车。**作用**：进入系统"设备状态"页，触发 hotfix 加载入口。
5. 屏幕底部**点"更新你的 Kindle"（Update Your Kindle）**。
6. 弹出确认对话框，点**确认**。
7. 设备自动重启。
8. 重启完成 → **回到桌面主界面** = hotfix 已成功，桥接回来了。

## 再次验证

回到桌面后，锁屏输入 `;log` 回车。右上角小日志图标**出现** = 桥接已恢复。

## 如果重打 hotfix 后仍不行

按顺序排查：

1. **bin 文件是否真的到位**？
   ```powershell
   Get-FileHash F:\update_hotfix_languagebreak.bin -Algorithm SHA256 | Select-Object -ExpandProperty Hash
   Get-FileHash .\LanguageBreak-1.0.1\update_hotfix_languagebreak.bin -Algorithm SHA256 | Select-Object -ExpandProperty Hash
   ```
   两个哈希**必须一致**。不一致 → Windows 文件锁静默写失败，重拷。见 [书库没有KUAL.md](./书库没有KUAL.md#peki-静默失败的另一种可能windows-文件锁) 的诊断法。

2. **是不是根本没进演示模式**？hotfix 依赖越狱状态。如果连演示模式都进不去，说明整个越狱链条断了，需要从头走 [../docs/01-越狱全流程.md](../docs/01-越狱全流程.md)。

## 官方逃生开关（不需要桥接的两个命令）

kindlemodding 官方 wiki 在 Troubleshooting 段列了两个**不依赖桥接、不依赖语言选择页**的开关。放在 Kindle 根目录一个**空文件**就能触发：

### `DONT_CHECK_BATTERY`

- **作用**：跳过电池电量检查，允许演示模式进入（正常演示模式要求电量 ≥ 50%）。
- **什么时候用**：正常路径推演示模式但 `;enter_demo` 无响应、或者电量低于 50% 想强制进入。
- **怎么放**：F: 根目录放一个空文件，名字正好是 `DONT_CHECK_BATTERY`（全大写，无扩展名）：
  ```powershell
  New-Item -ItemType File -Path F:\DONT_CHECK_BATTERY
  ```
- **注意**：这不是"跨过"中间态的命令。[卡在演示模式.md](./卡在演示模式.md) 里的"错误文字 + 配置设备按钮"中间态要靠秘密手势，不是靠这个文件。

### `DO_FACTORY_RESTORE`

- **作用**：下次开机自动做出厂恢复。
- **什么时候用**：卡在演示模式的中间态太久、或者不想再折腾想退回干净状态。
- **怎么放**：F: 根目录放一个空文件，名字正好是 `DO_FACTORY_RESTORE`（全大写，无扩展名）：
  ```powershell
  New-Item -ItemType File -Path F:\DO_FACTORY_RESTORE
  ```
- **注意**：会把所有已装内容（KOReader、KUAL、weread.koplugin、BinaryRenamer 等）全部清掉，等于从步骤 0 重来。慎用。
