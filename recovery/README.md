# Recovery Playbooks

本目录是 [data/playbook.yaml](../data/playbook.yaml) 中「偏离状态」的配套处置文档。每篇对应一个状态 id，由 agent 在探测到对应状态时指向本目录中同名文件。

## 状态 → 文档对照

| 状态 id | 偏离现象 | 对应步骤 | 处置文档 |
|---|---|---|---|
| **S03** | 演示模式异常（屏幕下方错误文字 + "配置设备"按钮 + 顶部无搜索栏） | 步骤 09 | [卡在演示模式.md](./卡在演示模式.md) |
| **S08** | 越狱桥接不活跃（;log 无输出） | 步骤 14 | [越狱桥接挂了.md](./越狱桥接挂了.md) |
| **S09** | 书库无 KUAL 项目（MRPI 装完仍无 KUAL） | 步骤 15 | [书库没有KUAL.md](./书库没有KUAL.md) |
| **S10** | USB 认不到设备（KOReader 运行时插 USB 不挂载） | 步骤 16+ | [USB认不到设备.md](./USB认不到设备.md) |
| —（软砖逃生） | 改系统服务后设备起不来（**本仓库不覆盖串口**） | — | [串口救砖指引.md](./串口救砖指引.md) |
| —（收尾经验） | 越狱脚本打补丁后未彻底还原后门 | — | [补丁后门还原.md](./补丁后门还原.md) |

## 与其它目录的关系

- **YAML 里的状态 id** 是本目录每篇文档的锚点：playbook.yaml 的 状态: 列表下 id: "S03" 对应 [卡在演示模式.md](./卡在演示模式.md)。
- **docs/01-越狱全流程.md** 是正常路径手册；本目录只处理偏离与收尾。
- 串口救砖、打补丁还原**不是本仓库覆盖范围**，仅做外部引用与预防提示。
